# English Words

Android-приложение для изучения английских слов по системе интервальных повторений.
Слова разбиты по уровням CEFR (A1–C2), уроки состоят из разных типов заданий, а приложение само напоминает, когда пора повторять.

Приложение работает офлайн, не требует регистрации и хранит все данные на устройстве.

## Возможности

### Обучение
- **Выбор слов карточками.** Свайп вправо — «Учить», влево — «Знаю». Слова, отмеченные «Знаю», вернутся на проверку через 30 дней.
- **Уровни A1–C2.** Выбираете уровень, а когда слова уровня заканчиваются, приложение само переходит на следующий.
- **Цель дня.** Настраиваемое число новых слов в день и кнопка «Выучить ещё».
- **Слова с предлогами** изучаются сразу вместе с ними: `belong to`, `interested in`, `pay for`.
- **Свои группы слов.** Можно собрать подборку из слов словаря или записать собственные слова и учить её отдельным уроком.

### Задания в уроке
Новое слово проходит путь от простого к сложному:

1. знакомство со словом (слово, перевод, озвучка);
2. выбор перевода;
3. выбор перевода на слух;
4. выбор английского слова по переводу;
5. составление слова из букв;
6. набор слова с клавиатуры.

В конце урока — задание «соедини пары»: английские слова и их переводы.
После ошибки задание возвращается в очередь, а в красной панели показывается правильный ответ и перевод вашего неверного ответа.

### Интервальные повторения
Расписание повторений:

| Повторение | Когда |
|---|---|
| 1-е | через 12 минут |
| 2-е | через 4 часа |
| 3-е | через сутки |
| 4-е | через 3 дня |
| 5-е | через неделю |
| 6-е | через месяц |

После шестого повторения слово считается закреплённым, дальше интервал удваивается. При ошибке слово возвращается на две ступени назад.

На каждом повторении — два задания на слово, одно из них набор с клавиатуры. Если повторять по расписанию нечего, доступна «Тренировка», которая не меняет расписание.

### Словарь
- Все слова с фильтрами по статусу (учу, закреплено, знаю, не начато) и по уровню языка.
- Слова, которые вы учите, отсортированы по времени до следующего повторения.
- Перевод показывается по нажатию на слово, рядом кнопка озвучки.
- Неточный перевод можно исправить прямо в приложении.

### Напоминания
- Уведомления в стиле Duolingo: о повторениях, о новых словах и о пропущенных днях.
- Настраиваемая частота и любое количество периодов тишины.

### Прочее
- Серия занятий и статистика по уровням.
- Озвучка слов встроенным синтезатором речи Android.
- Светлая и тёмная темы.

## Технологии

- Kotlin, Jetpack Compose, Material 3
- WorkManager — напоминания
- Google ML Kit Translate — автоматический перевод слов на устройстве
- Android TextToSpeech — озвучка
- Данные хранятся локально в JSON-файлах и SharedPreferences

Минимальная версия Android: 8.0 (API 26).

## Установка из релиза

1. Скачайте готовый APK файл из раздела [**Releases**](https://github.com/mumunikita/EnglishWords/releases/latest):
2. На телефоне разрешите установку приложений из источника, откуда открываете APK
3. Откройте скачанный `.apk` и нажмите **«Установить»**.
4. Запустите приложение.

Требуется Android 8.0 (API 26) или новее. Регистрация не нужна, все данные хранятся на устройстве.

При первом запуске понадобится интернет: один раз скачается языковая модель для перевода (около 30 МБ). На Android 13 и новее приложение также запросит разрешение на уведомления.

Если вы обновляете приложение поверх предыдущей версии, прогресс сохраняется. При удалении приложения все локальные данные также удаляются.

## Сборка (при необходимости)

1. Установите [Android Studio](https://developer.android.com/studio).
2. Откройте папку проекта через **File → Open** и дождитесь синхронизации Gradle.
3. Подключите телефон с включённой отладкой по USB или запустите эмулятор.
4. Нажмите **Run ▶**.

Чтобы собрать APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

### Первый запуск
Для автоматического перевода слов нужен интернет: один раз скачается языковая модель (около 30 МБ). После этого перевод и всё остальное работает без сети.

Для уведомлений на Android 13 и новее приложение запросит разрешение на показ уведомлений.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET` | однократная загрузка модели перевода |
| `POST_NOTIFICATIONS` | напоминания об уроках и повторениях |

## Структура проекта

```
app/src/main/java/com/example/englishwords/
├── MainActivity.kt   навигация и нижняя панель
├── Theme.kt          тема, цвета, формы, шрифты
├── Data.kt           модели и алгоритм интервальных повторений
├── Repo.kt           слова, прогресс, настройки, группы, уровни
├── LessonVm.kt       логика урока: порядок заданий, проверка ответов
├── LessonUi.kt       экраны заданий урока
├── SortUi.kt         выбор слов карточками
├── DictionaryUi.kt   словарь с фильтрами и поиском
├── GroupsUi.kt       свои группы слов
├── EditUi.kt         окно исправления перевода
├── Screens.kt        главная, статистика, настройки
├── Translate.kt      автоперевод через ML Kit
├── Speech.kt         озвучка и сравнение ответов
└── Reminder.kt       уведомления
```

## Где хранятся данные

Всё лежит во внутренней памяти приложения и удаляется вместе с ним:
прогресс по словам, группы, собственные слова, исправленные переводы и настройки.
Никакие данные не отправляются на сервер.
